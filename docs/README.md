# 教材の使い方

[教材メニュー](https://learn.fa-labo.com/)から教材を選びます。各教材の画面上部の **Japanese / English** で、操作の途中でも言語を切り替えられます。

## カチッとリレー

初めてなら、1面「ランプ」で起動ボタンを押し、点灯したら離してみてください。次に3面「自己保持」で同じことをすると、今度はボタンを離してもランプが点いたままです。停止ボタンを押すと消えます。2面「両手」では、キーボードの **1 と 2** を両方押すとプレスが動きます。

**盤と展開接続図**　線を選ぶと、盤と図で同じ番号の線を見比べられます。盤の端子を2つ順に選ぶと線を追加できます。広い画面では左に図、右に盤が並び、図の「縮小 −」を押すと盤が広がります。スマートフォンでは盤を拡大して左右にスクロールできます。

| 面 | 操作とクリアの目安 |
| --- | --- |
| 19面「配線直し」 | 図と盤を見比べて配線を直します。起動を押して離すと緑灯が点いたままになり、設定時間後にファンが回ります。停止を押して離すとファンが止まり、赤灯だけが点けばクリアです。分岐に使う端子が違っても、同じ動作ならクリアできます。 |
| 20面「ゼロから配線」 | 未配線・電源OFFの盤から始まります。図の線を選んで接続先を確認し、配線してから電源を入れます。起動前は赤灯だけ、起動を押して離すと緑灯だけ、停止を押して離すと再び赤灯だけが点けばクリアです。 |

## 機器あそび場

試したい部屋を選び、設定を一つずつ変えて機器の動きやグラフを見比べます。例えば「配線と発熱」では、長さを50m、ヒーターを3台にそろえ、電線の太さを変えると電圧降下の違いが分かります。故障したときは理由を読み、「部品を交換して直す」で再開できます。

## リレー式エレベーター

まず2Fを押し、呼びを記憶してから、走行・減速・着床・戸開閉までを観察します。回路は「呼びを覚える」「方向を決める」「戸と安全」「走る・止まる」「戸を開閉する」の役割で切り替えます。全体を見たいときは「全回路（詳しく）」を選べます。

操作と観察の教材で、配線変更はありません。数字キー1〜3でも呼べます。図は拡大縮小・高さ調整ができ、「最初に戻す」で1階の待機状態に戻ります。発見ノートと言語の選択は保持します。乗場の上り／下り呼びを区別しない3階建てのモデルです。図は動作説明用の模式図で、実機の全回路や安全装置を再現していません。

## 発見ノートの保存・引き継ぎ

発見はリレー全体で29件、機器の9部屋で計89件、エレベーターで5件あります。未発見の項目にはヒントが表示されます。見つけた項目は、このサイトを開いたブラウザーに自動保存されます。

- **別の端末やブラウザーで続ける**　元の発見ノートで「記録を書き出す」を押し、移行先で「記録を読み込む」から同じJSONファイルを選びます。3教材の発見が保存され、移行先の記録とまとめられます。以前の2教材だけの保存ファイルも読み込めます。
- **HTMLを直接開いて使う場合**　ブラウザーによっては教材ごとに記録が分かれます。その場合は各教材から書き出し、移行先で両方のファイルを読み込みます。
- **最初から集め直す**　「記録をクリア」を押し、確認画面でOKを選ぶと、開いている教材の記録をすべて消去します。あとで復元したい場合は先に書き出してください。

## 教材の数値と実機を見比べる

- モーターの始動グラフでは、0秒がスタートを押した時点です。左の1秒間で始動直前の電流を確かめてください。完全に停止していれば0Aから立ち上がり、インバータで減速中に再始動すれば、そのときの電流から続きます。55Aなどの値はこの教材の設定です。
- 温度の部屋では「リレーの接点溶着を再現」を押すと、温調器が出力を切ってもヒーターに電流が流れ続ける例を試せます。実機の接点寿命は、負荷の種類や電流、開閉頻度などの条件によって変わります。[オムロン「リレーの基礎知識」](https://components.omron.com/jp-ja/ds_related_pdf/CDPA-061.pdf)
- モーター保護の部屋では、1Eを過負荷保護、2Eを過負荷・欠相保護として扱います。2秒という欠相検出時間はこの教材の設定です。[オムロン「低圧開閉器 参考資料」](https://www.fa.omron.co.jp/guide/technicalguide/753/345/index.html)
- 配線と発熱の部屋の許容電流は、周囲温度30℃以下のビニルコードを例にしています。異なる種類の電線や敷設条件では値が変わります。[古河電工メタルケーブル「コードの許容電流」](https://www.furukawa-mc.jp/products/cable/clist/clist04.html)
- 測る部屋のPt100は、0℃で100.0Ω、50℃で119.4Ω、100℃で138.5Ωを表示します。[Fluke「Pt100 抵抗値の計算」](https://www.fluke.com/en-us/learn/tools-calculators/pt100-table-generator)
